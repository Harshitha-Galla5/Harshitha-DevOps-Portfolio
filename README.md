## Local Development

Clone the repository:

```bash
git clone https://github.com/Harshitha-Galla5/Harshitha-DevOps-Portfolio.git
```

Navigate into the project:

```bash
cd Harshitha-DevOps-Portfolio
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

---

## Production Build

Build the application:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

---

## Deployment

This portfolio is deployed using GitHub Pages.

Deploy command:

```bash
npm run deploy
```
